Task-05: Automated E-Commerce Checkout Flow
Objective

Automate the complete checkout process of an e-commerce website using Selenium.

Website

SauceDemo - https://www.saucedemo.com/

Testing Tool
Python
Selenium WebDriver
Google Chrome
Test Flow
Open SauceDemo
Login using valid credentials
Add a product to the cart
Open the shopping cart
Proceed to checkout
Enter customer information
Continue to checkout overview
Finish the purchase
Verify the success message
Expected Result

The checkout process should complete successfully and display:

"Thank you for your order!"
